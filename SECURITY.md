# Security Policy

Please do not report security vulnerabilities in public issues.

Report them privately through [GitHub Security Advisories](https://github.com/st4rgaze/laravel-telegram-logger/security/advisories/new). You will get a response within a few days, and a fix will be released as soon as possible with credit to you unless you prefer otherwise.

Examples of issues we treat as vulnerabilities: any path where the bot token, or data that redaction should have removed, reaches logs, exceptions, queue payloads or Telegram.
